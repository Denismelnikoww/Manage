# Матрица RACI проекта LabFlow

Матрица показывает распределение ответственности по ключевым работам и результатам проекта.

## Распределение ответственности

| Работа / результат | PM | LD | BE | FE | AN | QA | ЗК |
|---|---:|---:|---:|---:|---:|---:|---:|
| Устав, планирование и контроль проекта | A/R | C | I | I | C | I | C |
| Требования, Use Cases и критерии приёмки | C | C | C | C | A/R | C | C |
| OpenAPI, схема данных и матрица ролей | C | C | C | C | A/R | C | I |
| Репозиторий, Git-flow и CI/CD | I | A/R | C | C | I | C | I |
| Локальное окружение и контейнеризация | I | A | R | C | I | C | I |
| Backend: API и бизнес-логика модулей | C | C | A/R | C | C | C | I |
| Frontend: интерфейсы и интеграция с API | C | C | C | A/R | C | C | I |
| Тест-план и функциональное тестирование | C | C | C | C | C | A/R | I |
| Исправление дефектов по компонентам | C | A/R | R* | R* | C | C | I |
| Интеграция модулей и сквозное E2E-тестирование | C | A | R | R | C | R | I |
| Документация и подготовка портфолио | A/R | C | C | C | R | C | I |
| Приёмка результата по критериям проекта | R | C | C | C | C | R | A |
| Подготовка и проведение защиты | A/R | R | R | R | R | R | C |

## Обозначения

- **R (Responsible)** — выполняет работу.
- **A (Accountable)** — несёт итоговую ответственность за результат; для каждой строки назначен один A.
- **C (Consulted)** — консультирует, участвует в согласовании.
- **I (Informed)** — получает информацию о ходе или результате.

\* Дефекты исправляет владелец соответствующего компонента: Backend — BE, Frontend — FE, инфраструктура и CI/CD — LD. QA проверяет исправления.

1. **LabFlow** - трекер сдачи лабораторных. Веб-сервис для одной учебной группы: список работ, дедлайны, статусы (не начата / в работе / сдана / на доработке / принята), загрузка отчёта, комментарий преподавателя, уведомления в Telegram. Роли пользователей продукта: студент и преподаватель.

2. **ConsultSlot** - запись на консультации. Преподаватель публикует свободные слоты, студент бронирует и отменяет запись, приходят напоминания. Продукт простой, но слабо питает последующие лабораторные курса (бэклог, качество, статусы работ).

3. **SkillBoard** - доска стажировок для студентов программной инженерии. Карточки вакансий, отклик, статусы рассмотрения. Тема «рыночная», но для семестра рискованна: источники вакансий, модерация, больше ролей и интеграций.

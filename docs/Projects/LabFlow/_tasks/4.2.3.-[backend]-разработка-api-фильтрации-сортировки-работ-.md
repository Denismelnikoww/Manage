## Результат (feature/4.2.3)

`GET /api/v1/works` поддерживает:

- `status` — фильтр по статусу сдачи (`not_started` … `accepted`)
- `sort_by` = `order_num` | `deadline`, `sort_desc`
- `deadline_from` / `deadline_to` / `overdue`
- в ответе: `is_overdue`, `days_until_deadline`, `student_submission`

При создании ЛР автоматически создаются сдачи `not_started` для студентов группы.

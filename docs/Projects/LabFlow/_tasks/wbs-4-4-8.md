## Результат
- Зафиксированы технические API-сценарии загрузки и скачивания отчёта, включая выдачу и срок действия pre-signed URL (TTL 900 с, AWS SigV4, `Content-Disposition: attachment`).
- Описаны правила доступа студента и преподавателя (RBAC/ABAC), валидация расширений (.pdf, .docx, .zip) и сигнатур файлов (magic bytes), лимит размера (0 < size ≤ 20 971 520 байт), метаданные отчёта, таблица версий `reports` со связью 1:N к `student_submissions` и привязка объекта в приватном бакете MinIO `labflow-reports`.
- Согласованы форматы запросов/ответов, структуры данных и правила валидации для реализации на Backend (4.4.3) и Frontend (4.4.5), а также компенсирующие алгоритмы отката (`remove_object`) при сбоях СУБД.
- Актуализированы контракты в `openapi.yaml` (добавлены эндпоинты версий отчетов, коды ошибок 400, 409, 413, 500) и `Спецификация API (OpenAPI)`.

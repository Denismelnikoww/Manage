## Результат (feature/4.3.2-api-status)

- Таблица `submission_status_history` (FR-10 Could): from/to status, changed_by, comment_text, created_at
- `PATCH /api/v1/submissions/{id}/status` — FSM + RBAC по матрице 4.3.1:
  - student (владелец): `not_started` → `in_progress`
  - teacher: `submitted` → `accepted` (comment опционален)
  - teacher: `submitted` → `needs_work` (comment ≥ 5 обязателен → ещё и в `comments`)
  - `accepted` терминальный → `409 INVALID_SUBMISSION_STATE`
- `GET /api/v1/submissions/{id}/status-history` — история переходов
- Upload (4.4.3) тоже пишет историю при переходе в `submitted`

## Результат (feature/4.5.2-tg)

### Таблицы / поля (по Спецификации TG §4.1 и ERD)
- `notification_logs` — recipient_id, submission_id, event_type, message_text, status, attempts, last_error, next_retry_at, created_at, sent_at, telegram_chat_id
- `telegram_auth_tokens` — user_id, token (UK), expires_at, is_used, created_at (TTL 10 мин)
- `users.notifications_enabled` (default true), `users.telegram_username`

### aiogram3-бот
- пакет `backend/app/bot/` — polling, `/start` и `/start <token>` по шаблонам §3.2
- шаблоны HTML с `html.escape` (`templates.py`)
- сервис `telegram-bot` в `docker-compose.yml`
- env: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`, `TELEGRAM_SERVICE_TOKEN`, `BACKEND_INTERNAL_URL`

### Вне скоупа 4.5.2 (остаётся на 4.5.3)
- `POST /telegram/link-token`, `DELETE /telegram/unlink`, `POST /telegram/internal/bind`
- сервис отправки уведомлений + retry/очередь

Тесты: `backend/tests/test_telegram_wbs_452.py`
